# Скриншоты для входного аудита (сделать вручную)

Положите в эту папку 6 скриншотов с указанными именами. По каждому должно быть
понятно, что именно проверялось.

| Имя файла | Что показать | Что должно быть видно | Где взять |
|---|---|---|---|
| `01_repo_structure.png` | Структура проекта | Папки `backend/`, `landmark_app/`, `plan_of_realisation/`, `WIKI/` | VS Code / GitHub |
| `02_install_dependencies.png` | Сборка backend | Команда `docker compose up -d --build` и отсутствие ошибок | Терминал |
| `03_env_example.png` | Файл `.env.example` | Имена переменных без настоящих секретов | VS Code |
| `04_success_run.png` | Успешный запуск | `docker compose ps` (статусы Up/healthy) и `curl /healthz → 200` | Терминал |
| `05_app_working.png` | Работающая программа | Экран приложения Flutter **или** ответ `curl` со списком POI / JSON входа | Эмулятор / терминал |
| `06_git_status.png` | Состояние Git | Что изменения добавлены и сохранены (`git status`, `git log`) | Терминал |

> Подсказка: соответствующие команды и ожидаемые результаты приведены в
> `03_Инструкция_запуска.md` и в отчёте `01_Входной_аудит_проекта.docx`
> (раздел «Протокол запуска»). Готовый журнал запуска — в `logs/app_start_log.txt`.
