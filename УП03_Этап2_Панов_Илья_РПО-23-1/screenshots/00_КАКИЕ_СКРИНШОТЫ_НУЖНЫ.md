# Скриншоты для этапа 2 (сделать вручную)

Положите в эту папку 9 скриншотов с указанными именами. По каждому должно быть
видно реальную команду и её результат.

| Файл | Что показать | Команда |
|---|---|---|
| `01_clean_clone.png` | Проект склонирован в новую папку | `git clone https://github.com/Ilpaka/LandMark_App.git` |
| `02_setup_bat_success.png` | Успешная установка зависимостей | `scripts\setup.bat` (или `make setup`) |
| `03_make_help_or_make_check.png` | Вывод команд / успешная проверка | `make help` и `make check` |
| `04_docker_build_success.png` | Успешная сборка образов | `docker compose build` (или `make docker-build`) |
| `05_docker_compose_up.png` | Запущенные сервисы | `docker compose up --build` (или `make docker-up`) + `docker compose ps` |
| `06_app_opened_in_browser.png` | Программа открыта | браузер `http://localhost:8080/v1/places` (JSON) или окно Flutter-приложения |
| `07_linter_success.png` | Линтер отработал | `make check` / `scripts\check.bat` → «No issues found» |
| `08_formatter_success.png` | Форматтер отработал | `make format` / `scripts\format.bat` |
| `09_git_commit.png` | Коммит и push в ветку | `git log --oneline -5` и `git push` (ветка `up03-etap2-installation`) |

> Подсказка: на macOS вместо BAT-файлов используйте `make`-команды — результат
> тот же (они вызывают одни и те же инструменты). Полный список команд и адресов
> приложения — в `docs/01_Короткий_отчет_по_этапу_2.docx` и в `INSTALL.md`.
